# Vue frontend

This directory is reserved for Vue 3 + TypeScript + Vite.

Planned screens:
- Weekly planning calendar
- Capacity overview for Person A and Person B
- Content brief/editor with channel variants
- Review and approval inbox
- Version history and simulated handoff status

Bootstrap in the next implementation step with `npm create vue@latest .` and select TypeScript, Vue Router, Pinia, Vitest, ESLint and Prettier.
