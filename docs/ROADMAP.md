# Roadmap

## Milestone 1 — assignment prototype
- [ ] Structured synthetic input and five-idea weekly plan
- [ ] Three priorities and two reserves with rationale
- [ ] Capacity totals and over-budget warning/re-plan
- [ ] One complete production brief with two channel variants
- [ ] Versioned approval snapshot
- [ ] Simulated publishing payload with idempotency
- [ ] Weekly text report
- [ ] Four acceptance tests and honest test evidence

## Milestone 2 — Symfony application
- [ ] Symfony 7.4 + API Platform setup
- [ ] Doctrine entities, migrations and validation
- [ ] Domain services for planning, capacity, approval and handoff
- [ ] PHPUnit unit and integration tests

## Milestone 3 — frontend
- [ ] Vue 3 + TypeScript + Router + Pinia
- [ ] Weekly calendar and capacity view
- [ ] Content editor and approval inbox
- [ ] Version history and handoff status

## Milestone 4 — AI and knowledge
- [ ] Provider abstraction (mock / Ollama)
- [ ] Structured generation and output validation
- [ ] Document ingestion, chunking and embeddings
- [ ] pgvector retrieval and grounded generation (RAG)

## Milestone 5 — automation and operations
- [ ] n8n workflow exports
- [ ] Human notifications and manual fallback
- [ ] Secure secret management
- [ ] Logs, metrics, backups and CI
- [ ] Analytics with unknown-data handling and deduplication
